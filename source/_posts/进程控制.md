# fork
```C
pid_t fork(void);
// return 父进程返回子进程id，子进程返回0 错误-1
```
子进程是父进程的副本，获得父进数据空间、堆栈副本。**但不是共享存储空间。**

## sample
```C
#include "apue.h"

int glob = 6;
char buf[] = "a wirte to stdout\n";

int main(void)
{
    int var;
    pid_t pid;

    var = 88;
    if(write(STDOUT_FILENO, buf, sizeof(buf)-1) != sizeof(buf)-1)
        err_sys("write error");
    printf("before fork\n");

    if((pid = fork() )< 0)
    {
        err_sys("fork error");
    }
    else if(pid ==0)
    { // 子进程
        glob++;
        var++;
    }
    else
    { // 父进程
        sleep(2);
    }

    printf("pid = %d, glob = %d, var = %d\n", getpid(), glob, var);
}
```
输出如下
```shell
$ ./a.out 
a wirte to stdout
before fork
pid = 3327960, glob = 7, var = 89
pid = 3327959, glob = 6, var = 88


# 标准输出连到终端时候，它是行缓冲，否则是全缓冲
# 交互方式运行程序时，只printf一次是因为标准输出缓冲区由换行符冲洗。
# fork之前调用一次printf 但fork时，该行数据任在缓冲区，父进程数据空间复制到子进程中时，该缓冲区也被复制到子进程中。
# 所以输出重定向后得到printf输出行两次
./a.out > temp.out 
a wirte to stdout
before fork
pid = 3328053, glob = 7, var = 89
before fork
pid = 3328052, glob = 6, var = 88

```

- 父子进程执行先后顺序不确定
- 文件共享：fork父进程所打开的文件描述符被复制到子进程中。
- 子进程集成父进程资源包括：
  - 实际用户ID、实际组ID、有效用户ID、有效组ID
  - 附加组ID
  - 进程组ID
  - 会话ID
  - 控制终端
  - 设置用户ID标志和设置组ID标志
  - 当前工作目录
  - 根目录
  - 文件模式创建屏蔽字
  - 信号屏蔽和安排
  - 针对任一打开文件描述符的在执行时关闭标志
  - 环境
  - 连接的共享存储段
  - 存储映射
  - 资源限制
- 差异：
  - fork返回值
  - 进程ID
  - 文件锁
  - 子进程未处理的闹钟会被清除
  - 子进程未处理信号集置空

# vfork
## 与fork区别
- 子进程会调用exec或eixt
- 不将父进程地址空间完全复制到子进程中
- 子进程在调用exec或eixt前会在父进程的空间运行
- vfork保证子进程先运行，在子进程调用exec或exit之后父进程才会被调度（如果在这两个函数之前子进程依赖于父进程的动作，则会导致死锁）

## sample
```C
#include "apue.h"

int glob = 6;

int main(void)
{
    int var;
    pid_t pid;

    var = 88;
    printf("before vfork\n");

    if((pid = vfork() )< 0)
    {
        err_sys("vfork error");
    }
    else if(pid ==0)
    { // 子进程
        glob++;
        var++;
        _exit(0); // 子进程结束
    }
    
    // 父进程继续执行
    printf("pid = %d, glob = %d, var = %d\n", getpid(), glob, var);
}
```
输出
```shell
./a.out 
before vfork
pid = 3377232, glob = 7, var = 89 # 父进程输出的变量值被改变，子进程在父进程地址空间运行

```
